# mekotools/butterchurn

**Öffentliches Spiegel-Repo des MekoTools-Katalogs.** Enthält keine eigene
Software: veröffentlicht wird das fertige Container-Abbild, damit es **ohne
Anmeldung** gezogen werden kann.

- Werkzeug: MilkDrop-Visualizer auf Basis von Butterchurn (`jberg/butterchurn`, MIT)
- Bezug: `docker pull ghcr.io/mekotools/butterchurn:latest`
- Bauvorschrift: interne GitLab-Instanz, `tilllt/mekotools/mekotools-butterchurn-fbac2f6b`
